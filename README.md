# OJILZTAG.COM — Digital Solutions & Marketing Website

Public website: https://digital.ojilztag.com/

## Website scope
- Digital service marketing: websites, web applications, hosting and domain setup, business digitalization, education and student management workflows, event platforms, automation, integrations, creative design, multimedia and digital promotion.
- Audience and solution sections for businesses, institutions, event organizers, service providers, creators and teams.
- Project links: MY EVENT, CAROLIA 2026 and the Founder & CEO profile.
- Project enquiry form that prepares a WhatsApp message for the visitor to review and send.
- Standalone Privacy Policy and Terms & Conditions pages.
- Canonical metadata, Open Graph basics, Organization structured data, XML sitemap and robots.txt.

## Deployment
This repository is configured for the GitHub Pages site on the custom domain `digital.ojilztag.com`. Keep the `CNAME` file in the repository root. Publishing to the configured default branch triggers the Pages deployment workflow.

## Enquiry flow
The form uses the WhatsApp number configured in `index.html`. It opens a pre-filled message; the visitor must review and press Send. The current static form does not store enquiries in a website-side database. Do not add credentials, OTPs or private API keys to the public source.

## Pricing and claims
Displayed service prices are indicative starting prices. Scope, deliverables and final quotations must be agreed separately. Do not add unverified testimonials, certifications, guarantees, addresses or customer counts.
